# 《薄荷色氏族公约》 —— 肉鸽卡牌爬塔（纯静态网页版）

> 「这个世界的卡牌，都是从聊天记录里提取的精华。」
> —— 取材自 QQ 群「薄荷色氏族公约」（《星痕共鸣》氏族 #14106）的真实聊天记录

商业级肉鸽卡牌爬塔（Slay the Spire 式）的纯静态网页实现。无后端、无数据库、无美术资源文件，
全部画面由 CSS 矢量 + emoji 占位渲染，音效由 WebAudio 程序合成。构建产物可直接本地双击运行，
同时兼容 GitHub Pages 等任意静态托管。

## 快速开始

```bash
# 安装依赖（需 Node.js ≥ 20）
pnpm install

# 开发模式（热更新）
pnpm dev              # 打开 http://localhost:5173

# 生产构建（自动执行 测试 → 类型检查 → 打包）
pnpm build            # 产物输出到 dist/（单文件，可双击运行）

# 本地预览构建产物
pnpm preview

# 仅运行核心测试（含 jsdom UI 集成测试）
pnpm test

# 浏览器 E2E 冒烟（需先 pnpm exec playwright install chromium）
node e2e/smoke.mjs    # 自动打开构建产物走完 标题→选人→地图→战斗→出牌→结束回合
```

**直接玩**：`pnpm build` 后双击 `dist/index.html`（构建产物为**单文件自包含**，JS/CSS 全部内联，`file://` 双击即可运行，无需服务器）。

## 技术架构

```
src/
├── core/        # 无头逻辑核（零 DOM 依赖，可 Node 跑测）
│   ├── rng.ts           # 种子 PRNG + 4 子流（地图/洗牌/战斗/奖励），状态可序列化
│   ├── valuePipeline.ts # 五阶段数值修正管道（Base→Flat→%→受击倍率→减免→保底）
│   ├── hooks.ts         # 全局 Hook 总线（优先级调度 + 16 层递归熔断）
│   ├── actions.ts       # 效果 DSL 解释器（原子动作树：数值/牌堆/状态/流程）
│   ├── cards.ts / piles.ts / units.ts / buffs.ts
│   ├── combat.ts        # 分相确定性状态机（BattleInit→…→RoundEnd）+ 动作队列
│   ├── map.ts           # CSP DAG 地图生成（去交叉/内容约束/动态权重）
│   ├── encounter.ts     # 事件/商店/营地/宝箱引擎
│   ├── run.ts / save.ts # 单局状态机 + 双槽事务存档（Checksum 校验）
├── content/     # 数据驱动内容（职业/卡牌/怪物/Boss/遗物/事件，全部 TS 配置）
│   ├── classRuntime.ts  # 职业专属机制（以 Hook 挂载，引擎零职业硬编码）
├── view/        # 表现层（DOM + CSS 动画）
│   ├── main.ts          # 屏幕路由（标题→选人→地图→战斗→奖励→结算）
│   ├── combatView.ts    # 手牌扇形/点选+拖拽双模出牌/明牌意图/飘字/职业挂件
│   ├── mapView.ts / screens.ts / audio.ts
└── tests/       # Vitest（77 用例）：数值管道/PRNG/地图/无头战斗/敌人目标回归/内容校验/人物遗物行为/整局模拟/平衡性跑测/jsdom UI 集成
```

**测试体系（77 用例，`pnpm test`）**：
1. `core.test.ts` — 五阶段数值管道、PRNG 确定性与状态恢复、DAG 地图约束、无头战斗可复现
2. `enemy-target.test.ts` — 回归：敌人单体攻击必须命中玩家（曾出现怪物互殴的严重 bug）
3. `full-run.test.ts` — 两职业整局模拟直至通关/失败、存档往返一致性
4. `content-validation.test.ts` — 内容 Schema 断链检查（卡牌引用/Buff/资源/动作类型）
5. `ui.integration.test.ts`（jsdom）— 不依赖浏览器模拟点击：标题→选人→地图→战斗→点选出牌→结束回合

**核心工程特性**：

1. **种子级确定性（防 SL）**：整局由单一 Master Seed 驱动 4 条独立 PRNG 子流；PRNG 内部状态随存档持久化，
   刷新/读档后抽牌、怪物意图、掉落、商店完全一致，无法刷牌。
2. **无头核心 + 表现层解耦**：逻辑核不依赖 DOM，测试中以 400 回合上限自动出牌模拟整局通关，
   支持未来做平衡性批量跑测与录像回放。
3. **数据驱动**：所有卡牌/怪物/事件是纯数据配置 + 效果 DSL，引擎零硬编码；`pnpm test` 含内容 Schema
   校验（断链检查、非法动作类型、未知 Buff 等）。
4. **双槽事务存档**：主/备槽轮替 + CRC32 校验码，写坏自动回滚。
5. **触控双模出牌**：点选（选牌→选目标）与拖拽（越过 45% 出牌线释放，吸附最近目标）并行支持。
