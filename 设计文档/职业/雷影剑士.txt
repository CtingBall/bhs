二、 核心武器系统：【双形态流转】(Stance Switching Engine)

雷影剑士拥有常驻的 【形态切换】 机制，形态决定了基础攻击的判定范围与被动加成：

                    ┌─────────────────────────────────────────┐
                    │            【雷影·镰长刀】               │
                    └────────────────────┬────────────────────┘
                                         │ 自由流转切换
                     ┌───────────────────┴───────────────────┐
                     ▼                                       ▼
          ┌─────────────────────┐                 ┌─────────────────────┐
          │    【长刀形态】     │                 │    【镰刀形态】     │
          │    (Katana Form)    │                 │    (Scythe Form)    │
          │  - 单体精准破甲     │                 │  - 小范围群体扫荡   │
          │  - 暴击与单发高伤   │                 │  - 高频撕裂与 Debuff│
          │  - 契合: 居合斩流   │                 │  - 契合: 月刃召唤流 │
          └─────────────────────┘                 └─────────────────────┘

形态流转规则：

1.  打牌自然切换：卡牌自带形态标签（如带有 [长刀] 标签的卡牌打出时，自动将角色切为长刀形态；带有 [镰刀] 标签的卡牌切为镰刀形态）。
2.  形态固有被动：
      - 长刀形态：所有攻击对单体目标造成额外 +2 点锋锐伤害；
      - 镰刀形态：单体攻击卡牌自动获得 【顺劈】 特性（对目标相邻/全场其他敌人造成 40% 的溅射伤害）。

三、 核心专属资源：【雷之印】与【超高出力】(Thunder Seals & Overdrive)

        ┌────────────────────────────────────────────────────────┐
        │            雷之印计量槽 (Thunder Seals: 0 ~ 5)         │
        │             (默认上限: 5 枚 | 跨回合保留)               │
        └───────────────────────────┬────────────────────────────┘
                                    │ 获取途径
                                    ▼
        ┌────────────────────────────────────────────────────────┐
        │                 核心引擎: 【超高出力】                  │
        │    (单回合消耗全部费用 / 打出高负荷技能 / 触发满载)   │
        └────────────────────────────────────────────────────────┘

1. 【雷之印】基础规则

  - 容量上限：默认最大 5 个（UI 为刀镡上的 5 颗雷纹勾玉）。
  - 存留规则：战斗中跨回合保留，战斗结束重置。

2. 核心获取机制 ——【超高出力】(Overdrive)

雷之印不能随随便便获得，必须通过**【超高出力】**激发：

  - 触发条件：
    1.  打出带有 [超高出力] 词条的重型卡牌（通常为 2 费以上或消耗全部剩余能量）；
    2.  当单回合打出的卡牌总伤害达到一定阈值（如单回合输出 \ge 20 点）时，机能过载，[生成 1~2 枚雷之印]；
    3.  形态切换的瞬间（长刀 \leftrightarrow 镰刀），触发过载电弧，[生成 1 枚雷之印]。

四、 转职方向 A：【居合斩流】(Iai Slash Spec)

  - 战术定位：极限蓄力、单发超高爆发、雷霆万钧、大范围清场一闪。
  - 设计哲学：平时以长刀积攒雷之印与刀势，一旦出鞘，消耗全部雷之印打出毁天灭地的斩击。

[积攒 5 枚雷之印] ──► 开启【无穷雷霆之力】(印记常驻秒拉满) ──► 打出【居合斩】(单体天花板秒杀)
         │
         └──────────► 打出【一闪】(全场群体雷光居合，小怪瞬间蒸发)

核心机制与关键技能：

1.  特化终结技：【居合斩】(Iai Slash - 单体极限核爆)：
      - 费用：2 费（长刀形态）。
      - 效果：造成 12 点基础伤害。打出时消耗当前所有【雷之印】，每消耗 1 枚雷之印，本技能伤害 +150%，并附加 1 回合【麻痹/眩晕】。
      - (满 5 印消耗：基础伤害 \times (1 + 5 \times 1.5) = 8.5 倍伤害，单刀打出 100+ 巨额爆发)。
2.  群体特化技：【一闪】(Issen - 全体瞬移斩)：
      - 费用：1 费。
      - 效果：消耗 2 枚雷之印。化作一道雷光穿透全体敌人，造成 16 点雷电伤害。若成功击杀任意目标，返还 2 枚雷之印并抽 1 张牌。
3.  核心核心能力牌：【无穷雷霆之力】(Infinite Thunder)：
      - 类型：能力牌（Power），2 费。
      - 效果：进入雷神过载状态。本场战斗中，只要你以任何方式获得了【雷之印】（无论是 1 枚还是 2 枚），雷之印数量直接瞬间补满至上限（5 枚）！
      - (极具质变感的爽卡：只要能触发一次超高出力，后续每回合都能打出满印居合斩！)

五、 转职方向 B：【月刃召唤流】(Moonblade Summon Spec)

  - 战术定位：高频攻击、召唤月刃助战、0 费连击刷牌、触发展雷特效。
  - 设计哲学：以镰刀为主，消耗 3 个雷之印召唤出拥有独立行动或协同特性的**【月影 / 月刃】**，通过极高频次的 0 费连续斩击，疯狂触发附带特效。

                     ┌────────────────────────────────────────┐
                     │          消耗 3 枚雷之印: 【月影】     │
                     │        (召唤 1 柄浮空共鸣【月刃】)     │
                     └───────────────────┬────────────────────┘
                                         │ 持续在场 / 协同进攻
                 ┌───────────────────────┴───────────────────────┐
                 ▼                                               ▼
      ┌──────────────────────┐                        ┌──────────────────────┐
      │   【镰车】(Kama-Wheel)│                        │ 【霹雳连斩】(Rapid)  │
      │ 范围横扫 + 强行召月刃│                        │ 生成大量 0 费【连斩】│
      └──────────┬───────────┘                        └──────────┬───────────┘
                 │                                               │
                 └───────────────────────┬───────────────────────┘
                                         │ 高频命中触发
                                         ▼
                     ┌────────────────────────────────────────┐
                     │     能力牌: 【千雷闪影之意】(On-Hit)   │
                     │   (每次造成伤害，追加一道附带雷电冲击) │
                     └────────────────────────────────────────┘

核心机制与关键技能：

1.  特化核心召唤：【月影 / 月刃】(Moonblade Summon)：
      - 释放条件：消耗 3 枚【雷之印】激活。
      - 月刃属性：召唤 1 柄环绕自身旋转的幽月光刃（持续 3 回合或直到战斗结束）。
      - 协同效果：玩家每次打出一张攻击牌，月刃自动对相同目标发动一次 【月影追击】（造成 4 点雷暗伤害）。
2.  核心技能：【镰车】(Scythe Wheel - 强力召唤技)：
      - 费用：2 费（镰刀形态）。
      - 效果：对敌方全体造成 10 点回旋镰刃伤害。若当前没有月刃在场，无需印记直接免费召唤一柄【月刃】；若已有月刃，月刃的持续时间延长 2 回合。
3.  连击核心卡：【霹雳连斩】(Thunderous Rapid Slashes)：
      - 费用：1 费。
      - 效果：造成 6 点伤害。将 2~3 张【0 费·连斩】加入手牌（【连斩】：0费，造成 4 点伤害，附带消耗/Exhaust 属性）。
      - (精妙配合 5 张手牌上限：打出一张腾出位置，瞬间塞入 0 费连斩倾泻打出)。
4.  核心能力牌：【千雷闪影之意】(Will of Thousand Flashes)：
      - 类型：能力牌（Power），2 费。
      - 效果：雷霆附体。本场战斗中，只要你或你的月刃造成一次伤害，追加造成 2 点固定雷电真实伤害，并为目标施加 1
        层【感电/雷鸣】（感电：受到攻击时额外爆发出范围雷伤）。
      - (与【霹雳连斩】+【月刃追击】形成超高频多段触发机器，单回合跳字几十次！)
