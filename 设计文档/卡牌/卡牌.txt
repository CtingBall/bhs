商业级肉鸽卡牌爬塔架构设计规范书

核心领域模块：【卡牌系统】(Card Domain & Deck Engine)

第一章：卡牌模型与数据契约规范 (Card Domain Model)

卡牌是玩家在对战中直接发起操作的核心交互媒介。在数据驱动架构下，每张卡牌由**静态配置原型（CardConfig）与运行时动态实例（CardInstance）**分离组成。

┌───────────────────────────────────────────────────────────────────────────────────┐
│                           静态卡牌配置原型 (CardConfig)                           │
│   - 基础属性: ID / 基础费用(Cost) / 卡牌类型(Type) / 稀有度(Rarity) / 目标类型    │
│   - 标签矩阵: Tags[] (如: 攻击, 顺劈, 播种, 灌注, 瞬发, 连斩, 护盾猛击)           │
│   - 升级分支: UpgradeA (数值强化) / UpgradeB (机制质变分支)                        │
│   - 动作树负载: ActionTree (调用【效果】模块的复合原子动作树)                      │
└─────────────────────────────────────────┬─────────────────────────────────────────┘
                                          │ 实例化克隆 (Instantiate to Deck)
                                          ▼
┌───────────────────────────────────────────────────────────────────────────────────┐
│                           运行时卡牌实例 (CardInstance)                           │
│   - 唯一标识: InstanceID (UUID)                                                   │
│   - 动态费用: CurrentCost (受【寒冰灌注】、【荒川之寂灭】等效果动态修正)           │
│   - 临时修饰: IsTemporary(临时衍生) / IsEthereal(虚无) / IsRetain(保留)           │
│   - 附魔状态: Enchantments[] (局内获得的额外词条，如“附带剧毒”)                    │
└───────────────────────────────────────────────────────────────────────────────────┘

1.1 卡牌五大基础分类（Card Types）

每张卡牌必须显式归属于以下 5 种基础类型之一，类型直接决定出牌结算后的去向与交互规则：

| 卡牌类型 (Type)         | 核心职能与结算规则                         | 出牌后去向                  | 典型案例                    |
| :------------------ | :-------------------------------- | :--------------------- | :---------------------- |
| **1. 攻击牌 (Attack)** | 造成直接伤害、破甲、突刺与顺劈。打出时接入五阶段数值修正管道。   | **弃牌堆 (Discard)**      | 【自然轻击】、【暴怒劈斩】、【螺旋击刺】    |
| **2. 技能牌 (Skill)**  | 提供护甲、回复生命、抽取卡牌、调整资源与改变姿态。         | **弃牌堆 (Discard)**      | 【清滝绕珠】、【砂石斗篷】、【精神凝聚】    |
| **3. 能力牌 (Power)**  | 赋予永久光环被动。整场战斗永久生效，不参与后续洗牌。        | **永久消耗/离场 (PlayArea)** | 【无尽之炎魔】、【圣光守卫】、【风姿卓绝】   |
| **4. 状态牌 (Status)** | 战斗中由敌人/自身机制临时塞入手牌的负面干扰卡（或特定正向增益）。 | **回合结束丢弃/消耗**          | 【眩晕】、【灼伤】、【0费·连斩(正向状态)】 |
| **5. 诅咒牌 (Curse)**  | 局外事件或高难词缀塞入牌库的永久负面牌，通常无法打出或打出扣血。  | **保留或自伤消耗**            | 【虚妄寄生】、【沉重镣铐】、【贪婪之噬】    |

1.2 稀有度与分发权重（Rarity Matrix）

战利品与商店掉落中，卡牌分为 4 大稀有度档位，由独立的 RNG_Reward 伪随机数流控制：

                    ┌─── 普通卡 (Common): 60% 基础出率 (流派基础润滑剂)
                    │
[战利品卡池抽样] ───┼─── 罕见卡 (Uncommon): 30% 基础出率 (流派核心启动件)
                    │
                    ├─── 稀有卡 (Rare): 10% 基础出率 (带动态保底，质变大招)
                    │
                    └─── 特殊卡 (Special): 0% 常规出率 (仅通过事件、转职或衍生生成)

2.1 手牌硬上限 5 张控制法则（Hand Limit Protocol）

为了适配移动端操作聚焦与精简策略，本架构严格执行 5 张手牌硬上限：

1.  抽牌溢出拦截（Draw Overflow）：
      - 当手牌已有 5 张时，若系统继续触发 DrawCards 动作，多抽的卡牌直接进入【弃牌堆】（不产生手牌爆牌动画，并在屏幕提示“手牌已满”）；
      - 防卡死设计：部分特殊大天赋或遗物可临时将上限扩充至 8 张，但基础默认值永固为 5。
2.  回合结束丢弃（Turn-End Discard）：
      - 回合结束时，除带有 [保留 (Retain)] 词条的卡牌外，手牌区剩余所有卡牌强制移入【弃牌堆】。

2.2 确定性洗牌算法（Deterministic Reshuffle）

  - 当【抽牌堆】卡牌耗尽且需要抽牌时，将【弃牌堆】全量卡牌移入【抽牌堆】；
  - 调用 Fisher-Yates 伪随机置乱算法，随机源严格绑定 RNG_Deck 子种子流：

\text{Swap}(P[i], P[\text{RNG\_Deck.Next}(0, i)])

  - 工程价值：杜绝玩家通过刷新页面改变洗牌顺序（SL 防作弊），保证整局 100% 录像可复现。

第三章：费用判定与动态降费引擎 (Cost Evaluation)

卡牌打出前，必须经过**动态费用求值器（Dynamic Cost Evaluator）**进行合法性校验。

[配置表基础费用 (BaseCost)] ──► [全局光环减费] ──► [专属机制减费] ──► [单回合临时设费] ──► [最终打出费用]

1. 最终费用计算公式

\text{EffectiveCost} = \max\left(0, \text{BaseCost} - \sum \text{FlatDiscount} - \text{SpecDiscounts}\right)

2. 特殊费用类型支持

  - 固定费用（0 ~ 3 费）：标准常规消耗。
  - X 费用（X-Cost）：打出时消耗当前所有剩余能量 E，将 E 作为参数传入动作树执行 E 次（如：造成 E \times 8 点伤害）。
  - 动态减半费用（Half-Cost）：冰魔导师【冰霜之矛】在持有玄冰时触发：
    \text{EffectiveCost} = \lfloor \text{BaseCost} / 2 \rfloor = 1 \text{ 费}
  - 绝对归零覆盖（Zero-Override）：狂战士【荒川之寂灭】抽出的卡牌挂载 OverrideCost = 0 标记，本回合内无视基础费用强制 0
    费打出。

第四章：卡牌双分支变异升级系统 (Bifurcated Upgrades)

摒弃传统单调的“伤害+3”单一升级，卡牌支持 分支 A（数值极化） 与 分支 B（机制异变） 双向选择：

                              ┌───► 【分支 A: 刺骨冰矛+】(伤害由16提升至24点)
      【冰霜之矛】(基础形态) ──┤
                              └───► 【分支 B: 裂变冰矛+】(伤害不变，命中额外凝结1颗玄冰并分裂AOE)

升级维度对照表：

| 升级分支            | 升级侧重点             | 典型效果改造                                   |
| :-------------- | :---------------- | :--------------------------------------- |
| **分支 A（强化增强型）** | 放大核心数值、降低 1 点费用   | 基础伤害/护盾提升 40%\~50%，或费用 $2 \rightarrow 1$ |
| **分支 B（机制质变型）** | 附加新词条、扩大目标范围、衍生资源 | 单体攻击升级为【群体顺劈】；打出附加【播种 2】或【抽 1 张牌】        |

第五章：Web / 移动端手牌响应式交互与力场物理算法

在手机端，手牌排布采用自适应抛物线扇形力场模型（Dynamic Parabolic Fan-Field），彻底解决手指遮挡与操作误触。

                        /   最高点: 选中卡牌向上浮动 40% 且放大 1.3 倍   \
                       |                                                 |
                       |         [Card 3 (Focus)]                        |
                       |          /            \                         |
                       |    [Card 2]          [Card 4]                   |
                       |    /                        \                   |
                       | [Card 1]                  [Card 5]              |
                        \                                               /

1. 抛物线排布数学模型

当手牌数量 N \le 5 时，以屏幕底边中心为原点，第 i 张卡牌（0 \le i < N）的横向位置 X_i、垂直偏移 Y_i 与旋转角 \theta_i
公式为：

\text{NormalizedIndex } u_i = \frac{i - \frac{N-1}{2}}{\max(1, N-1)}

X_i = u_i \times \text{HandSpreadWidth}(N)

Y_i = -a \cdot (X_i)^2 + \text{BaseOffsetY}

\theta_i = u_i \times \text{MaxRotationAngle} \quad (\text{标准最大倾角: } 12^\circ)

2. 触控避让力场（Touch Repulsion Field）

  - 当玩家手指触碰或滑过手牌区域时，系统计算触控点与各卡牌中心的距离 D_i；
  - 距离最近的卡牌 C_{\text{focus}} 向上浮起 50px 并放大至 1.3 倍（卡面文字清晰无遮挡）；
  - 位于其左侧的卡牌施加向左推力 \vec{F}_{\text{left}}，右侧卡牌施加向右推力
    \vec{F}_{\text{right}}，向两侧动态散开，为聚焦卡牌让出展示空间。

3. 双模出牌操作判定（Dual-Input State Machine）

  - 点选模式（Tap Mode - 移动端单手主推）：
      - Tap Card \rightarrow 卡牌悬浮放大锁定 \rightarrow 目标单位亮起指示光环；
      - Tap Target \rightarrow 瞬间出牌；Tap Blank Area \rightarrow 取消选中归位。
  - 拖拽模式（Drag Mode - PC/平板快速出牌）：
      - 按住卡牌向上拖过“出牌基准线（屏幕高度 45%）”：指向性卡牌拉出贝塞尔曲线瞄准，全屏/自身技能化为能量圈，松手即释放。

第六章：战利品生成与动态保底轮盘 (Loot & Pity Engine)

战斗胜利后的“三选一卡牌奖励”通过**动态权重轮盘算法（Dynamic Pity Roulette）**生成，确保流派成型率：

[触发战后掉落] ──► [读取当前职业卡池白名单] ──► [稀有度保底轮盘判定] ──► [流派标签相关度加权] ──► [输出3张卡牌]

1. 稀有卡动态保底补偿机制（Rare Pity System）

  - 基础出率：普通怪战后出现稀有（金卡）的基础概率为 -2%（偏向罕见与普通）；
  - 递增补偿：玩家每遇到一场未出现稀有卡的战斗，稀有卡权重累计 +1.5\%；
  - 一旦抽中稀有卡，权重重置为基准值；精英怪（Elite）战后保底至少包含 1 张罕见卡，首领（Boss）战后必出 3 张稀有卡供选择。

2. 跨流派桥梁卡协同加权（Synergy Weighting）

  - 系统动态扫描玩家当前牌组中占比最高的 2 个机制标签（例如森语者的 [Smite] 与 [Restoration]）；
  - 战利品池中同时带有这两个标签的**“桥梁卡”出现权重自动提升 50%**，极大辅助玩家在爬塔中途实现流派顺畅转型与复合构筑。
